# JPEG XL lossless encode, stage 3, 2026-11-02

Stage 3 of `image.jxl.encode` (`wave5-jxl-encode3`). Stage 2 is
`jxl-encode2-20261102.md`, and its method (corpus totals through a
scratch program, and A/Bs through `convert-tails-20261102/ab.sh`) is
used here unchanged. docs/slop/jxl-encode.md has the design.

| commit | change                                                         |
| ------ | -------------------------------------------------------------- |
| leaves | default's tree may grow to 1024 leaves (was 2048), decision 71 |

Machine: Intel Xeon Processor @ 2.60GHz (4 vCPUs, AVX-512; a shared cloud
host, so only paired ratios are steady), Linux 6.1, Zig 0.16.0 ReleaseFast
for this CPU; libjxl 0.12.0, `cc -O3 -march=native`, one thread.

## Leaves: 1024 at default

The owner chose 1024 leaves for `default` over stage 2's 2048 (decision
71), trading 0.15% of size for time. Corpus totals, two runs of each
build interleaved on core 3 (`jxl-encode3-20261102/leaves/corpus.txt`):

| default leaves | corpus bytes | time (s), two runs |
| -------------- | ------------ | ------------------ |
| 2048           | 14,630,805   | 28.3, 28.0         |
| 1024           | 14,652,929   | 25.8, 26.1         |

+0.15% bytes for 0.92× the time. Against cjxl e7 the corpus total goes
from 1.003 to 1.005 (geomean 0.932 to 0.933); per class:

| default leaves | icons total | ≤1 MP total | >1 MP total | all total | all geomean |
| -------------- | ----------- | ----------- | ----------- | --------- | ----------- |
| 2048           | 0.878       | 0.996       | 1.008       | 1.003     | 0.932       |
| 1024           | 0.878       | 1.000       | 1.008       | 1.005     | 0.933       |

A/B on the e7 rows (`jxl-encode3-20261102/leaves/summary.txt`), 1024
leaves over 2048, beside libjxl, 5 rounds on core 3:

| class | rows | 1024 over 2048 | 1024 over libjxl e7 | 2048 over libjxl e7 |
| ----- | ---- | -------------- | ------------------- | ------------------- |
| icons | 13   | 1.00           | 0.60                | 0.60                |
| ≤1 MP | 23   | 1.09           | 0.89                | 0.82                |
| >1 MP | 7    | 1.11           | 1.15                | 1.02                |

Icons never reach 1024 leaves, so they do not change (16 rows' files
differ, all above icon size). Peak RSS of a pass over the corpus: 126.7
MiB against 130.2 (libjxl e7 260.8).
